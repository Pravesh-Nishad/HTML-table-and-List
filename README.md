This repository contains HTML examples created to practise HTML tables, different types of lists, and their structure.

## Projects Included
1. HTML Table
2. HTML Ordered List
3. HTML Unordered List
4. HTML Nested List
5. HTML Table with Rowspan and Colspan

## Technologies Used
- HTML5

## Learning Objectives
- Understanding HTML table structure.
- Practising table rows, headings, and data.
- Using rowspan and colspan attributes.
- Creating ordered and unordered lists.
- Understanding nested lists.
